SIPO: Serial-In Parallel-Out Architecture

This register accepts data exactly one bit at a time (Serial In) on each rising edge of the divided clock, but all 8 integrated bits are continuously available on the output wires simultaneously (Parallel Out).

Serial Data Input (SDI) The state of BTN0 dictates the data entering Bit 0. Holding BTN0 high (pressed) inputs a 1; leaving it unpressed inputs a 0. The previous Bit 7 is discarded completely (no circular feedback).
Parallel Output vs. SISO Unlike a Serial-In Serial-Out (SISO) register where you must wait 8 clocks just to read the final cascaded bit, this SIPO design allows immediate tapping of all intermediate flip-flops (LD0-LD7) instantly.
Testing Challenge: Assembling 10110010

To assemble the binary byte 10110010, you must enter it bit-by-bit from MSB to LSB. Time your button presses with the clock edges to shift in: 1, then 0, then 1, 1, 0, 0, 1, 0!

// 1. Clock Divider
reg [25:0] cntr;
always @(posedge clk) cntr <= cntr + 1;
wire slow_clk = cntr[25];

// 2. SIPO Shift Register Logic
reg [7:0] shift_reg;
always @(posedge slow_clk) begin
    // Shift bits left by 1, inject BTN0 into Bit 0

end
