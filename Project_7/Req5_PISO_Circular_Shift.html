Synchronous Operation

Buttons BTN0 and BTN1 act as clock enables for their respective bytes. Data operations resolve precisely on the rising edge of the slow clock.

[00] Rotate All 16 bits shift left. Bit 15 wraps seamlessly to Bit 0.
[01] Load Lower BTN0 asserted. sw[7:0] loads into [7:0]. Upper byte holds its value.
[10] Load Upper BTN1 asserted. sw[7:0] loads into [15:8]. Lower byte holds its value.
[11] Parallel Load Both asserted. Both bytes simultaneously load sw[7:0].

Req 5 Verilog Implementation

// 1. Clock Divider
reg [25:0] cntr;
always @(posedge clk) cntr <= cntr + 1;
wire slow_clk = cntr[25];

// 2. Synchronous Register Logic
reg [15:0] shift_reg;
always @(posedge slow_clk) begin
    if (btn[1] && btn[0]) 
        shift_reg <= {sw, sw};
    else if (btn[1]) 
        // Hold lower byte
        shift_reg <= {sw, shift_reg[7:0]};
    else if (btn[0]) 
        // Hold upper byte
        shift_reg <= {shift_reg[15:8], sw};
    else 
        // Rotate left
        shift_reg <= {shift_reg[14:0], shift_reg[15]};
end

// 3. Physical Output Mapping
assign led = shift_reg[9:0];
// RGB LED B {Blue, Green, Red}
assign rgb_b = shift_reg[15:13]; 
// RGB LED A {Blue, Green, Red}
assign rgb_a = shift_reg[12:10];
