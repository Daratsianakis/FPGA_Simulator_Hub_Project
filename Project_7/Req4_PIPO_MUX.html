Implementation 1: Button as Clock

In this design, always @(posedge btn[0]) is used. The register only captures the switch states at the exact moment BTN0 is pressed (transitions from 0 to 1). Holding the button down does nothing to the register.

PIPO Register (BTN0) The 8-bit Parallel-In Parallel-Out register captures the state of all 8 switches. Depending on the mode, BTN0 acts either as a direct noisy clock, or a clean synchronous Clock Enable.
2:1 Multiplexer (BTN1)
  • BTN1 = 0: Passes the raw SW data (I0) directly to LEDs.
  • BTN1 = 1: Passes the stored PIPO data (I1) to LEDs.

Verilog Implementation

// 1. Multiplexer Logic
assign led = btn[1] ? stored_data : sw;

// 2. Sequential Register Logic

    stored_data <= sw;
