Sequential PIPO vs Combinational Shifter

This architecture combines a clocked storage register (PIPO) and instantaneous logic (Barrel Shifter). Changes to switches instantly update the Shifter output and LEDs, but the base data being shifted does not change until BTN0 is pressed.

PIPO Register (BTN0) The 8-bit Parallel-In Parallel-Out register captures the state of all 8 switches ONLY on the rising edge of BTN0. When the button is released, the register ignores the switches and holds its data steady.
Barrel Shifter Controls
  • SW[3:0]: Shift Amount (0-8; 9-15 cap at 8).
  • SW[5:4]: Mode (00=LSL, 01=LSR, 10=ROL, 11=ROR).
  • SW[6]: Fill Bit (Used in Shifts, ignored in Rotates).
  • SW[7]: Unused by shifter.

Project 7 Challenge Verilog Implementation

// 1. Sequential PIPO Register
reg [7:0] stored_data = 8'b00000000;
always @(posedge btn[0]) begin
    stored_data <= sw[7:0];
end

// 2. Combinational Barrel Shifter Logic
wire [3:0] raw_shamt = sw[3:0];
wire [3:0] shamt     = (raw_shamt > 8) ? 8 : raw_shamt;
wire [1:0] mode      = sw[5:4];
wire       fill_bit  = sw[6];

reg [7:0] shift_out;
always @(*) begin
    case (mode)
        // Shift Left (LSL)
        2'b00: shift_out = (stored_data << shamt) | ({8{fill_bit}} & ~(8'hFF << shamt));
        
        // Shift Right (LSR)
        2'b01: shift_out = (stored_data >> shamt) | ({8{fill_bit}} & ~(8'hFF >> shamt));
        
        // Rotate Left (ROL)
        2'b10: shift_out = (stored_data << (shamt % 8)) | (stored_data >> (8 - (shamt % 8)));
        
        // Rotate Right (ROR)
        2'b11: shift_out = (stored_data >> (shamt % 8)) | (stored_data << (8 - (shamt % 8)));
    endcase
    
    // Edge case: Rotating by exactly 8 returns original data
    if (mode[1] && shamt == 8) begin
        shift_out = stored_data;
    end
end

// 3. Physical Output Mapping
assign led = shift_out;
