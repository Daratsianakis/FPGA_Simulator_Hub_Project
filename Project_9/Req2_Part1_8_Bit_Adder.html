1. Why operand registers?

There are only eight switches, but the adder needs two independent eight-bit values. The first register stores operand A, and the second stores operand B. Each register has eight numbered storage bits, so the same eight switches can supply each operand at a different time.

2. Load the first operand

Set SW7 through SW0 to the desired binary value. Press BTN0 to capture the switch values into register A. The orange stored bits and the orange bus leading into the adder show the retained value. Moving the switches afterward does not change A.

3. Load the second operand

Change the switches and press BTN1. The second register captures the new value while the first register retains its old one. Both register buses then enter the arithmetic unit simultaneously.

4. How addition works

The addition operator combines the two complete eight-bit operands. Internally, addition is built from per-bit sum and carry logic, but behavioral Verilog lets the synthesis tool implement that circuitry. The correct unsigned result can require nine bits because 255 plus 255 equals 510.

5. Read the output

The live result field includes all nine bits. The physical two-digit hexadecimal display shows the low eight bits, matching the two-digit assignment arrangement. The upper carry is identified separately so it is not silently lost.

6. Try a carry-out

Load 255 into A and 1 into B. The full result is 256, so the carry-out is 1 and the two displayed low hex digits are 00.

end
